# Smart Career Advisor

An AI-powered career advisory web app built with Python, Groq API, and Streamlit.

## What it does
- Takes your skills and years of experience as input
- Uses Llama 3.1 AI model to analyse your profile
- Suggests best job roles, skill gaps, and 6-month learning path

## Tech Stack
- Python
- Groq API (Llama 3.1)
- Streamlit

## How to run
1. Install dependencies: `pip install streamlit groq`
2. Add your Groq API key in `career_advisor.py`
3. Run: `python -m streamlit run career_advisor.py`
